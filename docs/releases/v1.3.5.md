# AIMaster v1.3.5 · 紧凑面板与浮窗恢复

- 重新整理主面板，使用左侧导航切换功能页，语言、主题与更新入口常驻侧栏。
- 卡片按内容自动撑高，减少空白并避免裁切；长内容统一通过页面滚动查看，历史重置公告可展开阅读。
- 重置公告与通知支持中文译文；启动或从托盘打开时，可补发当天尚未发送的重置提醒。
- 保存悬浮窗开启状态，程序启动或更新重启后恢复浮窗及原有设置；手动关闭后不再自动打开。
- 清理任务标题中的消息包装与图片标记，改善任务名称显示。

## 下载

- `AIMaster-win-x64-standalone.zip`：Windows x64 完整独立版，包含 .NET 运行时，推荐使用。
- `AIMaster-win-x64-lightweight.zip`：Windows x64 轻量版，需要 .NET 8 Desktop Runtime x64。
- 两个 ZIP 均附带 `.zip.sha256` 校验文件，支持应用内检查更新并原地安装。

## English

- Redesigned the dashboard with left navigation and persistent language, theme, and update controls.
- Cards grow with their content to reduce empty space and clipping; long content uses page scrolling, and earlier reset announcements can be expanded.
- Added Chinese reset announcement text and missed-reminder catch-up for the current day when opening the app.
- Restores an enabled floating monitor after startup or an update, preserving its settings. Closing the monitor explicitly disables automatic restoration.
- Cleans message wrappers and image markup from task titles.

Choose the standalone package for an included .NET runtime, or the lightweight package if .NET 8 Desktop Runtime x64 is already installed. SHA-256 checksum files accompany both packages.
