# AIMaster v1.3.6 · 通知中心与重置提醒

- 重置提醒改用 Windows 应用通知，横幅消失后可在通知中心查看，默认一天后到期；点击通知打开 AIMaster。
- 区分通知投递请求和通知中心留存确认，投递失败或系统关闭通知时保留当天补发机会。
- 主面板和悬浮窗显示最新重置提示，点击“已知晓”后同步隐藏；新的预告、公告或账号恢复记录会再次提示。
- 从来源文本中识别明确的预告时间并换算为当地时间；无法明确识别时保留原文。
- 改善最新重置预告的选择与补发，并为通知投递状态提供说明。

## 下载与系统要求

- 需要 Windows 10 1809 或更新版本（含 Windows 11），x64 架构。
- `AIMaster-win-x64-standalone.zip`：完整独立版，包含 .NET 运行时，推荐使用。
- `AIMaster-win-x64-lightweight.zip`：轻量版，需要 .NET 8 Desktop Runtime x64。
- 两个 ZIP 均附带 `.zip.sha256` 校验文件，支持应用内检查更新并原地安装。
- 便携版会在当前用户开始菜单中创建 AIMaster 入口，用于通知身份和点击激活。

## English

- Reset reminders now use Windows app notifications, remain in Notification Center after the banner disappears, and expire after one day. Clicking a notification opens AIMaster.
- Delivery requests and confirmed Notification Center retention are tracked separately. Failed or disabled delivery remains eligible for same-day catch-up.
- The dashboard and floating monitor share a dismissible reset reminder. New previews, announcements, and account recovery records can show a new reminder.
- Explicit reset preview deadlines are converted to local time; ambiguous source text is left unchanged.
- Improved selection and catch-up of the latest preview and added notification delivery status text.

Requires Windows 10 version 1809 or later (including Windows 11), x64. The standalone package includes .NET; the lightweight package requires .NET 8 Desktop Runtime x64. Both include SHA-256 checksum files. Portable installations create a per-user Start menu entry for notification identity and activation.
