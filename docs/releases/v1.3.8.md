# AIMaster v1.3.8 · 双额度悬浮窗与重置提醒修复

- 悬浮窗同时显示 5 小时和周剩余额度；悬停可分别查看重置时间与额度采集时间。
- 主面板与悬浮窗共享最新官方额度读数，避免悬浮窗继续显示旧缓存；较早请求的延迟响应不会覆盖新读数。
- 修复空闲时 5 小时窗口的重置时间随查询滑动，导致反复提示“账号额度已恢复”的问题。未使用的窗口不再误报恢复，实际恢复仍可正常提醒。
- 新增 DeepSeek 模式，支持账户余额、可选平台用量，以及 Deep Code 本地任务监控。凭证使用 Windows DPAPI 加密保存在本机，不包含在发布包中。
- 修复 Windows 任务栏分组身份，并改善已有固定快捷方式的兼容处理。

## 下载与系统要求

- Windows 10 1809 或更新版本（含 Windows 11），x64 架构。
- `AIMaster-win-x64-standalone.zip`：完整独立版，包含 .NET 运行时，推荐使用。
- `AIMaster-win-x64-lightweight.zip`：轻量版，需要 .NET 8 Desktop Runtime x64。
- 两个 ZIP 均附带 `.zip.sha256` 校验文件，支持应用内检查更新并原地安装。
- DeepSeek 平台用量接口可能随平台改版变化；用量读取失败不影响余额显示。

## English

- The floating monitor shows five-hour and weekly quota remaining together, with individual reset and capture times on hover.
- The dashboard and floating monitor share the latest official quota reading. Late responses from older requests cannot replace a newer reading.
- Fixed repeated quota-recovery notifications caused by an unused five-hour window moving its reset deadline with each query. Unused windows no longer trigger false recovery alerts; actual recovery remains detectable.
- Added DeepSeek balance monitoring, optional platform usage, and local Deep Code task monitoring. Credentials are protected locally with Windows DPAPI and excluded from release packages.
- Fixed Windows taskbar grouping identity and improved compatibility with existing pinned shortcuts.

Requires Windows 10 version 1809 or later (including Windows 11), x64. The standalone package includes .NET; the lightweight package requires .NET 8 Desktop Runtime x64. Both ZIPs include SHA-256 checksums and support in-place updates. The optional private DeepSeek platform usage interface may change; usage failures do not block balance monitoring.
