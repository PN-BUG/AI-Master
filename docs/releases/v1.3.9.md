# AIMaster v1.3.9 · 额度预测与界面优化

- 修复周额度预测误用主 5 小时额度的问题；缺少周额度数据时不再使用短窗口代替。
- 消耗预测支持在一周和 5 小时之间切换，分别查看账号或本机的消耗速度和剩余额度走势。
- 5 小时预测按实际重置窗口显示小时刻度。
- 优化主面板双额度展示和卡片布局，统一主窗口与关于窗口的应用图标。
- 打包前检查 .NET SDK，避免仅安装运行时时进入失败的构建流程。

## 下载与系统要求

- Windows 10 1809 或更新版本（含 Windows 11），x64。
- `AIMaster-win-x64-standalone.zip`：完整独立版，包含 .NET 运行时。
- `AIMaster-win-x64-lightweight.zip`：轻量版，需要 .NET 8 Desktop Runtime x64。
- 两个 ZIP 均附带 `.zip.sha256` 校验文件，支持应用内更新。

## English

- Fixed weekly forecasts incorrectly using the primary five-hour quota. Missing weekly data no longer falls back to a short quota window.
- Switch forecasts between weekly and five-hour windows for account-wide or local-device usage.
- Five-hour charts use hourly labels within the actual reset window.
- Improved dual-quota presentation, card layouts, and application icons.
- Packaging checks for a usable .NET SDK before building.

Requires Windows 10 version 1809 or later, x64. The standalone package includes .NET; the lightweight package requires .NET 8 Desktop Runtime x64. Both ZIPs have SHA-256 checksum attachments.
