# AIMaster v1.3.7 · 任务监控与内存优化

- 主面板、悬浮窗和后台监控共用任务快照与连接，改善两窗任务状态一致性及本地记录变化后的刷新。
- 改善异步输入问题与答复的识别，减少任务已经继续执行却仍显示等待输入的情况。
- 通过本地 Codex 桌面管道只读跟随实际待处理审批，区分“等待批准”和“等待输入”；连接断开或内部协议不兼容时回退到本地执行记录。
- 优化大型日志的流式解析、缓存回收及共享用量账本的增量更新，降低后台监控的内存与重复扫描开销。
- 独立版关闭程序集压缩，减少运行时解压后长期占用的私有内存；EXE 体积增加，下载 ZIP 仍保持压缩。
- 中文重置预告显示日期、两位 24 小时时间及北京时间或当地时区，并说明实际到账以账号额度为准。
- 当前重置预告与历史公告分开显示，支持手动刷新信号。

## 下载与系统要求

- 需要 Windows 10 1809 或更新版本（含 Windows 11），x64 架构。
- `AIMaster-win-x64-standalone.zip`：完整独立版，包含 .NET 运行时，推荐使用。
- `AIMaster-win-x64-lightweight.zip`：轻量版，需要 .NET 8 Desktop Runtime x64。
- 两个 ZIP 均附带 `.zip.sha256` 校验文件，支持应用内检查更新并原地安装。
- 桌面审批跟随依赖 Codex 的内部本地协议，兼容性随 Codex 版本变化。

## English

- The dashboard, floating monitor, and background monitoring share task snapshots and a connection, improving task consistency and refresh after local record changes.
- Improved detection of asynchronous input requests and replies so resumed tasks do not remain marked as awaiting input.
- Read-only observation of pending approvals through the local Codex desktop pipe distinguishes awaiting approval from awaiting input. Disconnections or incompatible internal protocols fall back to local execution records.
- Streamed large-log parsing, bounded caches, and incremental shared-usage ledger updates reduce monitoring memory and repeated scans.
- The standalone build disables assembly compression to reduce retained private memory. Its executable is larger; ZIP downloads remain compressed.
- Chinese reset previews show a date, two-digit 24-hour time, and Beijing or local timezone, with a reminder that actual account quota determines availability.
- Active reset previews are displayed separately from past announcements, with manual signal refresh available.

Requires Windows 10 version 1809 or later (including Windows 11), x64. The standalone package includes .NET; the lightweight package requires .NET 8 Desktop Runtime x64. Both include SHA-256 checksum files. Desktop approval observation depends on Codex's internal local protocol and may vary across Codex versions.
